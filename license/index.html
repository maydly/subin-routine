면허 필기 — 실전 문제풀이

읽기만 하면 안 외워져. 직접 풀어보면서 헷갈리는 숫자·함정을 몸에 붙이는 용도야. 틀려도 괜찮아 — 필기는 떨어져도 다음날 바로 다시 봐.

📝 실전 모의고사

실제 시험 그대로 — 40문항 · 40분 타이머 · 100점 만점. 푸는 동안엔 정답을 안 알려주고, 다 풀면 한 번에 채점돼. 60점 이상이면 합격이야. (문항 배점 2점·3점 섞여서 실제처럼 계산돼.)

🔀 칠 때마다 100문항 은행에서 랜덤 40문항이 뽑히고, 보기(선지) 순서도 매번 섞여 — 같은 세트가 안 나와서 진짜 연습이 돼.

시간 안에 다 못 풀면 자동으로 채점돼. 모르는 건 찍고 넘어가 — 실제 시험도 60점이면 붙어.

📚 학습 모드 (한 문제씩 바로 채점)
